# Инструкция для агента: включить продукт «CRM» (amoCRM + Telegram)

Ты — агент, выполняющий настройку через браузер Chrome в аккаунтах владельца.
Код уже в ветке `main`, миграции базы уже применены. Выполняй шаги по порядку.

## ⛔ Правила безопасности

1. Ничего не удалять и не менять в существующих ресурсах сверх того, что
   написано ниже. В Coolify и Supabase работают другие проекты — их не трогать.
2. Секреты (токены, ключи) — только в защищённое место владельца. Не вставлять в
   поисковые строки, чаты, документы. В финальном отчёте — ГДЕ сохранено, не ЧТО.
3. Шаг не получается или экран выглядит иначе — остановись и напиши, что видишь.
4. Веди «Блокнот результатов» — значения, нужные на следующих шагах (📝).

## Что должно быть на руках (спросить владельца, если нет)

- Доступы: Coolify (Hetzner), amoCRM (владелец аккаунта), админка Audio
  Analytics (вход владельца), Telegram-чат с ботом.
- 📝 Токен Telegram-бота и id чата — у владельца, из сервиса уведомлений.
- 📝 Адрес админки (например `https://admin.<домен>`).

## Шаг 1. Переменные окружения и перезапуск бэкенда (Coolify)

1. Открыть Coolify → приложение `audio-analytics` → **Environment Variables**.
2. Добавить три переменные (значения из блокнота):
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — id чата (несколько — через запятую);
   - `DASHBOARD_URL` — адрес админки без слэша в конце.
3. Сохранить и нажать **Redeploy**. Дождаться, пока оба контейнера (`api`,
   `worker`) снова в состоянии Running.
4. Проверка: открыть админку → в шапке меню три кнопки: «Скрипты», «Аналитика»,
   **«CRM»**. Нажать «CRM» → страница «Разборы CRM» открывается без ошибок.
   Если видна ошибка «выполните миграцию 018» — остановись и сообщи.

## Шаг 2. Приватная интеграция в amoCRM и долгосрочный токен

1. Войти в amoCRM → **Настройки** (внизу слева) → **Интеграции** →
   **«+ Создать интеграцию»** → **«Внешняя интеграция»**.
2. Заполнить: название `Audio Analytics CRM`; ссылка для перенаправления —
   адрес админки из блокнота; доступ — **полный** (сделки, контакты, задачи,
   примечания, чаты). Сохранить.
3. Открыть созданную интеграцию → вкладка **«Ключи и доступы»** →
   **«Долгосрочный токен»** → сгенерировать (срок — максимальный).
   📝 Скопировать токен сразу: показывается один раз.
4. 📝 Записать **поддомен** аккаунта — часть адреса до `.amocrm.ru`
   (например, адрес `https://ladystretch.amocrm.ru/…` → поддомен `ladystretch`).

## Шаг 3. Подключить amoCRM в админке

1. Админка → **CRM → Настройки → вкладка «Интеграция»**, секция **amoCRM**.
2. Ввести поддомен, домен `amocrm.ru`, вставить долгосрочный токен →
   **«Подключить»**.
3. Ожидаемо: зелёный огонёк «Подключено», название аккаунта, список
   «Воронки и этапы из amoCRM». Красная ошибка — остановись и перепиши её текст.
4. Нажать **«Синхронизировать сейчас»** → зелёное сообщение «Синхронизация
   прошла: сделок N, событий …».

## Шаг 4. Вебхук в amoCRM (сообщения из чатов)

Без него текст переписки не попадёт в разбор — API amoCRM его не отдаёт.

1. В админке, в той же секции amoCRM, карточка **«Вебхук — сообщения из
   чатов»** → **«Скопировать»** адрес (он содержит ключ).
2. В amoCRM → **Настройки → Интеграции** → найти **«Webhooks»** → открыть →
   **«Добавить вебхук»** → вставить адрес.
3. Отметить события — ровно те, что перечислены в админке под адресом:
   входящее и исходящее сообщение в чате; сделка добавлена, изменена, смена
   статуса; примечание добавлено в сделку; задача добавлена, изменена.
   Сохранить.
4. Проверка: написать тестовое сообщение в любой чат сделки в amoCRM (или
   попросить владельца), обновить вкладку «Интеграция» в админке →
   «Вебхуков получено: 1» (или больше).

## Шаг 5. Критерии, правила воронки, расписание, Telegram

1. **CRM → Настройки → «Критерии»**: пустое состояние предлагает четыре
   готовых критерия — у каждого нажать **«Взять за основу»** → **«Сохранить»**.
   В итоге четыре активных критерия.
2. Вкладка **«Промпт и правила»** → поле **«Правила воронки»**: заменить
   названия этапов на те, что показаны в «Интеграции» в списке «Воронки и
   этапы из amoCRM», дословно, в том же порядке. Остальной текст не трогать.
3. Там же ниже: переключатель **«Разбирать день сам — ежедневно в 20:00»**
   включён, час разбора **20:00**, часовой пояс **Asia/Tbilisi**. → **«Сохранить»**.
4. Строка **«Сводка в Telegram»**: должно быть «настроена» (зелёный огонёк).
   Нажать **«Отправить пробное»** → в Telegram-чате появляется сообщение
   «CRM — проверка связи». Если «не настроена» — вернуться к шагу 1.
5. Вкладка **«Интеграция»** → внизу **«Менеджеры CRM и сотрудники»**: каждому
   менеджеру из amoCRM выбрать сотрудника админки → **«Сохранить
   сопоставление»**. Нет подходящего сотрудника — оставить «не сопоставлен» и
   отметить это в отчёте.

## Шаг 6. Пробный разбор

1. **CRM → «Разборы»** → в шапке выбрать сегодняшнюю дату → **«Разобрать
   день»**. Строка дня появляется со статусом «В очереди» → «Разбирается» →
   через несколько минут **«Готово»** (страница обновляется сама).
2. **«Открыть разбор»**: есть цифры дня, карточки сделок с метками и
   «Что не так». Если сделок нет — в CRM за день не было переписки; это не
   ошибка, повторить завтра после 20:00.
3. На странице дня нажать **«В Telegram»** → сводка приходит в чат.
