# Инструкция для агента: ответы администраторов в разборе CRM

CRM уже настроена по `docs/AGENT_CRM_SETUP.md`. Это продолжение: после
обновления разбор видит ответы администраторов, а через Wazzup — и их текст.
Правила безопасности — те же, что в основной инструкции: ничего лишнего не
трогать, секреты только в админку и в защищённое место владельца, на
непонятном экране остановиться и описать, что видишь.

## Шаг 1. Обновить сервер

1. Coolify → приложение `audio-analytics` → проверить, что ветка — `main`.
2. **Redeploy**, дождаться, пока `api` и `worker` снова Running.
3. Админка → **CRM → Настройки → «Интеграция»** → карточка amoCRM →
   **«Синхронизировать сейчас»**. В зелёном сообщении должно появиться
   **«сообщений в чатах N»** с N больше нуля. Первая синхронизация забирает
   неделю, поэтому может идти минуту-две; если пишет «не всё за раз», нажать
   ещё раз.
4. Под адресом вебхука amoCRM теперь семь событий с реальными названиями.
   Сверить с настройками Web Hooks в amoCRM: отмечены ровно они. Лишних
   событий нет, «Исходящего сообщения» в amoCRM нет — так и должно быть.

## Шаг 2. Подключить Wazzup

1. В личном кабинете Wazzup найти API-ключ (раздел интеграций, «API»).
   Раздела нет — API может быть не включён в тариф: остановись и сообщи
   владельцу.
2. Админка → **CRM → Настройки → «Интеграция»** → карточка **Wazzup** →
   вставить ключ → **«Подключить»**.
3. Если появилось «В Wazzup уже указан адрес для вебхуков…» — **не нажимать
   «Заменить адрес и подключить»**: этим адресом пользуется другой сервис.
   Перепиши адрес из сообщения в отчёт и спроси владельца.
4. Проверка: попросить владельца отправить из amoCRM сообщение клиенту в
   WhatsApp (или отправить самому в сделке, которую назовёт владелец). Через
   минуту обновить вкладку → в карточке Wazzup **«Ответов с текстом: 1»** или
   больше. Если вебхуки приходят, а ответов с текстом 0 — переписать цифры из
   карточки в отчёт.

## Шаг 3. Разобрать заново 8 и 9 октября

1. **CRM → «Разборы»** → строка 8 октября → открыть → **«Разобрать заново»**.
   Дождаться «Готово». То же для 9 октября.
2. Проверить сделку **Qeta Xucishvili**: в переписке должен быть ответ
   администратора. Его текст покажется как «текст недоступен» — за прошлые
   дни Wazzup текстов не пришлёт, только с момента подключения. Важно, что в
   разборе больше нет «ответа от администратора не последовало».
3. Записать в отчёт новые цифры дня: сколько сделок, с замечаниями,
   критичных, «без ответа клиенту», «Ответ клиенту в среднем».

## Финальный отчёт владельцу

- Результат «Синхронизировать сейчас» после обновления (текст сообщения).
- Подключился ли Wazzup и что в его карточке через час работы: вебхуков,
  ответов с текстом, «ждут сделку», «без сделки».
- Цифры 8 и 9 октября до и после повторного разбора.
- Текст всех ошибок, если были, и на каком шаге.
